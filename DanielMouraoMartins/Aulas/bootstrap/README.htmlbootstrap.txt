# Pokémon — Página de Série

## 📌 Sobre o projeto

Este projeto foi desenvolvido como atividade da **3ª Avaliação**, com o objetivo de criar uma página web sobre uma série favorita utilizando HTML5 e Bootstrap 5.

A série escolhida foi **Pokémon**, que acompanha as aventuras de Ash Ketchum e seu parceiro Pikachu em busca de novos desafios e amizades.

## 🎯 Objetivo

Desenvolver uma página web utilizando HTML semântico, Bootstrap e recursos visuais para apresentar informações sobre a série Pokémon.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript do Bootstrap
- Imagens PNG externas

## 📋 Recursos implementados

O projeto apresenta os seguintes elementos:

- **HTML Semântico:** utilização das tags `header`, `nav`, `main`, `section`, `article` e `footer`.
- **Bootstrap via CDN:** utilização do framework Bootstrap 5 para estilização e organização da página.
- **Cards:** apresentação dos personagens Pikachu, Charizard, Squirtle e Bulbasaur.
- **Breadcrumb:** navegação de contexto no topo da página.
- **Carousel:** carrossel de imagens com três slides, indicadores e botões de navegação.
- **Layout Responsivo:** adaptação da página para diferentes tamanhos de tela.
- **CSS personalizado:** estilos incluídos diretamente no arquivo HTML por meio da tag `style`.

## 📁 Estrutura do projeto

```text
pokemon/
└── index.html
```

O projeto foi desenvolvido em um único arquivo HTML, contendo a estrutura da página, os estilos CSS e as referências ao Bootstrap.

## 🖼️ Imagens

As imagens dos personagens foram utilizadas em formato PNG por meio de links externos, incluindo recursos do PokeAPI.

## 🚀 Como executar o projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html`.
4. Execute utilizando a extensão Live Server.
5. A página será exibida no navegador.

**Observação:** é necessário ter acesso à internet para carregar o Bootstrap e as imagens externas.
